# 拼多多订单导出工具

在[拼多多移动网页版订单页](https://mobile.pinduoduo.com/orders.html)读取当前账号订单，在本机生成 CSV 账单或 JSON 数据文件。界面使用原生 Web Components 和表单控件，用户脚本没有运行时外部依赖。

## 安装

请使用近期版本的浏览器和 Tampermonkey 等用户脚本管理器。本仓库重写版尚未发布；[旧公开版本](https://greasyfork.org/zh-CN/scripts/581924)不等同于本仓库版本。

从源码安装需要 Git、Node.js 22.12+（22 系列）、24 系列或 26+，以及 npm。请克隆仓库并获取完整历史和 tags，再在仓库目录运行：

```sh
npm ci
npm run build
npm run preview
```

在终端显示的本地预览地址打开 `/pdd-order-export.user.js`，由脚本管理器完成安装。

版本由 Git 自动推导，源码 ZIP 无法直接构建。发布与 Greasy Fork 同步见[贡献指南](CONTRIBUTING.md#提交与发布)。

## 导出订单

1. 登录官网订单页，点击右下角「导出账单」。
2. 设置日期与格式。默认本月至今天、CSV；清空日期表示不限，起止日均包含。日期按订单号估算，不等同于支付时间。
3. 选择是否包含支付与物流详情；「高级选项」中可调整每页订单数和最多读取页数。
4. 点击「开始导出」。完整非空结果自动发起下载，也可再次下载 CSV 或 JSON。

关闭对话框后任务继续；「停止并保留结果」会取消后续请求。取消、达到上限、请求失败或数据异常时，结果标记为不完整，需要手动点击「下载部分 CSV/JSON（不完整）」。空结果不生成文件。

CSV 一行一个订单，包含店铺、商品、订单金额、状态及可选支付与物流详情。合计是订单金额，未扣除退款，不代表实际支出；金额缺失或异常时会提示未计入笔数。JSON 包含订单、详情和任务状态，便于检查及进一步处理。

## 数据与限制

- 任务和结果仅保存在当前页面内存中；刷新、关闭页面或开始新任务会清空已有结果。需要的文件请及时下载。
- 数据可能包含地址、手机号等个人信息。脚本不设置额外的上传服务，也不持久化登录凭据；请妥善保管导出文件，勿上传至公开仓库或问题反馈。
- JSON 备份解析后的订单和详情，保留字段、数组及数字/字符串类型；大整数和小数不会被改为字符串或舍入。不保留响应原文的空白、重复键或完整详情 HTML。CSV 金额按整数分计算，异常或超出安全整数范围的金额留空；合计溢出时界面会提示。编号及超长数字字段的文本保护可能显示前置单引号。
- 「完整」表示接口返回有效空页，且选中数据没有已知缺失，不保证服务端历史绝对完整。日期估算、非公开接口变化和页面生命周期仍可能影响结果。

当前版本有单元、Node 集成和真实浏览器自动测试；曾通过本机代理完成授权登录态采集及逐笔响应核对。本轮修复尚未重新验证线上登录态，脚本管理器安装和官网 CSP 也未完成验证。
