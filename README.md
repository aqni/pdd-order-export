# 拼多多订单导出工具

在[拼多多移动网页版订单页](https://mobile.pinduoduo.com/orders.html)收集当前账号订单，在本机导出 CSV 账单或 JSON 数据。

## 安装

支持近期版本的 Edge、Chrome。安装 Tampermonkey 后，从 [Greasy Fork](https://greasyfork.org/zh-CN/scripts/581924) 安装脚本。

从源码安装需要 Git、Node.js 和 npm，版本要求见[贡献指南](CONTRIBUTING.md#开始开发)。克隆仓库并获取完整历史与 tags 后运行：

```sh
npm ci
npm run build
npm run preview
```

打开终端显示的预览地址，页面会自动跳转到用户脚本，由 Tampermonkey 提示安装。脚本版本由 Git 推导，下载的源码 ZIP 无法直接构建。

## 使用

1. 登录官网订单页，点击右下角「导出账单」。
2. 设置日期范围，留空表示不限；选择是否读取支付与物流详情。
3. 点击「开始收集」，完成后选择「导出 CSV」或「导出 JSON」。

关闭面板后任务继续；「停止并保留结果」可取消后续请求。取消、出错或达到页数上限时，可手动导出标记为「不完整」的部分结果。CSV 生成失败时请尝试 JSON；反馈问题前须脱敏。

## 注意事项

- 结果仅保存在当前页面内存中，刷新、关闭页面或开始新任务后会丢失，请及时导出。
- 日期按订单号估算，起止日均包含，不等同于支付时间；订单金额未扣除退款，不代表实际支出。
- CSV 一行一个订单。用表格软件导入时，将订单号、快递单号列设为文本，避免长数字或前导零变化。
- JSON 保留解析后的订单、详情和任务状态；采用普通 JSON 数值精度，大整数或高精度小数可能舍入。
- 导出文件可能含地址、手机号等个人信息，请妥善保管，勿直接上传到公开仓库。

接口并非公开 API，「完整」仅表示本次遍历没有已知缺失，不保证覆盖全部历史。
